# CLAUDE.md

Context for Claude Code in this repository.

## What this repo is

A base template for **Strapi 5.61** (TypeScript, Node 22) with Docker. It is the starting point for new projects: each project created from it must be renamed and generate its own secrets (see "Using this template" in the README).

Because of that, prefer **generic, reusable** changes. Do not add logic specific to one project to the template base; if needed, suggest placing it in `src/api/` or `src/extensions/` as a clearly marked example.

## Key structure

- `config/` — Strapi configuration (`database.ts`, `server.ts`, `admin.ts`, `plugins.ts`, `middlewares.ts`, `api.ts`) and per-environment overrides in `config/env/`.
- `src/api/` — content types, controllers, services and routes (only `.gitkeep` for now).
- `src/extensions/` — plugin or core extensions.
- `src/admin/` — admin panel customization (`app.example.tsx` and `vite.config.example.ts` are templates and are not loaded as-is).
- `database/migrations/` — migrations.
- `types/generated/` — types **generated by Strapi**. Do not edit by hand.
- `public/uploads/` — uploaded files. Git-ignored; never commit them.

## Commands

```bash
npm install
npm run develop   # development with autoReload
npm run build     # builds the admin panel
npm run start     # production, no autoReload
```

Docker:

```bash
docker compose -f docker-compose.dev.yaml up --build   # development
docker compose up -d --build                           # production
```

PostgreSQL is expected on the host (`host.docker.internal`), unless a service is added to the compose file.

## Conventions

- Code, comments and commit messages: **English**. User-facing documentation may be in another language.
- Do not edit `types/generated/`, `dist/`, `.strapi/` or `node_modules/`.
- After changing content types, Strapi regenerates `types/generated/`; review that diff and do not clean it up by hand.
- When adding environment variables, also update `.env.example` (without real values) and the README table.

## Secrets and environment

- Never read, print or commit `.env`, `.env.dev`, `.env.prod` or real secret values. `.env.example` is public and only contains example values, which **must not be reused**.
- Secrets (`APP_KEYS`, `*_SALT`, `*_SECRET`, `ENCRYPTION_KEY`) are generated per project.

## Before considering a task done

1. `npm run build` must pass (compiles TypeScript and the admin panel).
2. If you touched Docker, validate the relevant `Dockerfile` / compose file.
3. Check that `git status` does not include `.env*` files, `dist/`, `public/uploads/` or `.claude/settings.local.json`.
